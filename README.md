# 🔐 Random Password Generator (Python)

## 📌 Overview
A command-line Random Password Generator built in Python that creates strong and secure passwords based on user-defined criteria.

This project was developed during internship practice to strengthen Python skills in string manipulation, randomness, and user input handling.

---

## ✨ Features
- 🔑 Generates strong random passwords  
- ⚙️ Customizable password length  
- 🔤 Includes letters, numbers, and symbols  
- 💻 Lightweight CLI tool  
- 🚀 Fast password generation  

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Concepts Used:** Random module, String manipulation, User input
